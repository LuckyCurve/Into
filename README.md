# Into · 兴趣雷达

记录「最近让我心里动了一下的东西」：一句话，加一个 1~5 的「温度」。
不写长篇，不打分焦虑，只是把那些让你微微一动的小事，安静地收进来。

它不是 Todo、不是笔记、不是打卡工具——你不需要「完成」任何事，
只是偶尔回看，发现自己这段时间，原来在关心这些。

---

## 为什么是 Into

我们习惯了用工具去「管理」生活：待办、习惯、目标、效率。
但有些东西不适合被管理——比如「今天在街角咖啡店坐了一会儿，很舒服」，
比如「傍晚去河边散步，风吹得温柔」。它们没有截止日，也不需要被完成。

Into 想做另一种收集：**观察兴趣，而不是管理人生。**

- 你只负责留下「心里一动」的瞬间，剩下的交给时间。
- 原始文字是不可动摇的核心；任何分类、标签、关键词都只是后来对它们的「解读」，
  永远不覆盖你写下的原话。
- 录入永远是首页。回看与汇总藏在另一个入口（顶部「写一点 / 看看」切换），
  不喧宾夺主，也不催你复盘。

---

## 它能为你做什么

**写一点**
想到就说，一句话 + 一个温度（从「淡淡的」到「心里发暖」），保存即结束。
三步之内完成，不逼自己写长篇。

**看看**
按时间范围回看自己的记录，支持多关键词搜索；
同时给出一份可解释的统计：记录条数、平均温度、1~5 的温度分布。
不是冷冰冰的仪表盘，而是「最近的我」的轮廓。

**关键词**
后端用中文分词，从你的记录里提取反复出现的词，
帮你看见自己最近在反复惦记什么——而不是你「应该」关心什么。

**示例数据**
想先预览「看看」里的分析与关键词长什么样，又还不想写？
点「生成示例数据」，会插入一批本地示例记录（刻意混入了反复出现的主题词），
方便你立刻看到分析效果。

- 生成示例**只在数据库为空时可用**：一旦你已经有记录，就不再让你塞示例，
  免得和你的真实小事混在一起。
- 清理示例数据也**只在「全部都是示例」时才放开**。如果库里混入了你的真实记录，
  这个按钮会自动禁用——它本就是为清示例而设，绝不会误删你的真实数据。

**开机自启与托盘**
可设置登录后自动在后台启动；关窗口时收进系统托盘，不打扰，也不丢数据。

**更新检查**
应用会安静地检查是否有新版本（一次只读请求，失败也不打扰你）；
发现新版本时，顶栏出现一个 `New` 标记，点它即可前往查看。

**自绘的暖色窗口**
没有冰冷的 Windows 原生黑框：藕粉底、珊瑚点缀，
整条顶栏可拖拽，八个热区自由缩放。

## 我们坚持的几条原则

- **本地优先，隐私优先**：没有云端、没有账号、没有遥测、没有第三方分析，
  也不发起任何外部网络请求。数据全部留在你本机的 `AppData`，
  用系统自带的 SQLite 存储，不依赖任何外部服务。
- **极低输入成本**：想到 → 打分 → 保存，结束。
- **原始输入不可动摇**：你写的话是唯一的真相；分析只是解读，绝不改写原句。
- **观察，而非管理**：不做打卡、效率、完成度。

## 设计与基调

为了避免「记账 / 金融」那种冷冰冰的调性，Into 采用**暖樱珊瑚**配色
（藕粉底 + 珊瑚主点缀 + 玫瑰反馈），全程不引入任何外部字体或资源。
若日后觉得色调偏移，会优先在色相上做调整（樱粉 / 莓果 / 抹茶），
而不是套用奶油底 + 赤陶红这类常见的 AI 默认搭配。
